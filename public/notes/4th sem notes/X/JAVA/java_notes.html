1.1 Introduction to Java

Why Java?

Java is one of the most popular programming languages because it is platform-independent (Write Once, Run Anywhere), object-oriented, secure, robust, and has a huge ecosystem of libraries.

📌 Key Concept
Java source code (.java) is compiled by the Java Compiler (javac) into Bytecode (.class file). This bytecode is then interpreted/executed by the Java Virtual Machine (JVM) — which exists for every platform. That's why Java is platform-independent.

JVM vs JRE vs JDK

TermFull FormWhat it containsUsed by
JVMJava Virtual MachineExecutes bytecode; provides memory management, garbage collectionRuntime execution
JREJava Runtime EnvironmentJVM + standard class librariesRunning Java apps (no compilation)
JDKJava Development KitJRE + compiler (javac) + debugger + toolsDeveloping Java apps

Java Source File Structure

// 1. Package declaration (optional, must be first)
package com.example;

// 2. Import statements

// 3. Class declaration (filename must match public class name)
public class HelloWorld {
    // 4. main() - entry point of every Java program
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}

Compilation & Execution

TERMINAL

# Run: JVM executes the bytecode
java HelloWorld

1.3 Object Oriented Programming Concepts

Class & Object

A class is a blueprint/template. An object is a real-world instance of a class.

JAVA
public class Student {
    // Attributes (instance variables)
    int rollNumber;
    String name;
    String branch;
    String email;

    // Constructor (PYQ 2023-24!)
    public Student(int rollNumber, String name, String branch, String email) {
        this.rollNumber = rollNumber;
        this.name = name;
        this.branch = branch;
        this.email = email;
    }

    // Method
    public void display() {
        System.out.println("Roll: " + rollNumber + " Name: " + name);
    }

    public static void main(String[] args) {
        // Creating objects
        Student s1 = new Student(101, "Rahul", "CSE", "r@mail.com");
        Student s2 = new Student(102, "Priya", "IT", "p@mail.com");
        s1.display();
        s2.display();
    }
}
Output

Roll: 102 Name: Priya

The Four Pillars of OOP

Encapsulation

Wrapping data (variables) and methods into a single unit (class), and restricting direct access using access modifiers.

JAVA
public class BankAccount {
    private double balance; // hidden from outside

    public double getBalance() { return balance; } // getter

    public void deposit(double amount) { // setter with validation
        if (amount > 0) balance += amount;
    }
}

Inheritance

One class (subclass/child) inherits properties and methods of another class (superclass/parent) using the extends keyword.

JAVA
class Animal {           // Superclass
    String name;
    void eat() { System.out.println(name + " is eating"); }
}

class Dog extends Animal {  // Subclass
    void bark() { System.out.println(name + " says Woof!"); }
}

public class Test {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.name = "Tommy";
        d.eat();  // inherited from Animal
        d.bark(); // Dog's own method
    }
}
Output
Tommy is eating
Tommy says Woof!

Polymorphism (PYQ – Very Important!)

The ability of a single method/reference to behave differently based on context. Two types:

TypeAlso calledResolved atMechanism

JAVA – METHOD OVERLOADING (Compile-time)
class Calculator {
    int add(int a, int b)          { return a + b; }
    double add(double a, double b)  { return a + b; }
    int add(int a, int b, int c)   { return a + b + c; }
    // Same name, different parameters = Overloading
}
JAVA – METHOD OVERRIDING (Runtime) [PYQ 2023-24]
class Shape {
    void displayArea() {
        System.out.println("Area of generic shape");
    }
}

class Rectangle extends Shape {
    double length, width;
    @Override
    void displayArea() {  // overrides parent method
        System.out.println("Area = " + (length * width));
    }
}

public class Test {
    public static void main(String[] args) {
        Shape s = new Rectangle(); // upcasting
        ((Rectangle)s).length = 5;
        ((Rectangle)s).width = 3;
        s.displayArea(); // calls Rectangle's version at runtime!
    }
}
Output
Area = 15.0

1.4 Packages

A package is a namespace that organizes related classes and interfaces, preventing naming conflicts.

JAVA
// File: com/myapp/MathUtils.java
package com.myapp;

public class MathUtils {
    public static int square(int n) { return n * n; }
}

// File: Main.java – using the package
import com.myapp.MathUtils;
import static com.myapp.MathUtils.square; // static import

public class Main {
    public static void main(String[] args) {
        System.out.println(square(5)); // no class name needed!
    }
}
💡 Naming Convention
Packages use reverse domain name: com.companyname.projectname. Class names are PascalCase. Method names are camelCase.

2.1 Exception Handling

An exception is an unexpected event that disrupts normal program flow at runtime. Java's exception handling lets you respond to errors gracefully instead of crashing.

Exception Hierarchy

FeatureChecked ExceptionUnchecked Exception
Detected atCompile timeRuntime
Must handle?Yes (try-catch or throws)No (optional)
ExamplesIOException, SQLExceptionNullPointerException, ArithmeticException, ArrayIndexOutOfBoundsException

Keywords: try, catch, finally, throw, throws

JAVA – Complete Exception Demo [PYQ 2023-24 & 2024-25]
public class ExceptionDemo {

    // throws declares that method might throw this exception
    static void checkAge(int age) throws IllegalArgumentException {
        if (age < 0) {
            throw new IllegalArgumentException("Age cannot be negative!");
        }
        System.out.println("Valid age: " + age);
    }

    public static void main(String[] args) {
        try {
            int result = 10 / 0;          // ArithmeticException
        } catch (ArithmeticException e) {
            System.out.println("Caught: " + e.getMessage()); // / by zero
        } finally {
            System.out.println("Finally always runs!"); // always executes
        }

        // Multiple exceptions (PYQ 2024-25)
        try {
            String s = null;
            s.length();                       // NullPointerException
        } catch (NullPointerException | ArrayIndexOutOfBoundsException e) {
            System.out.println("Null or array error: " + e);
        }
    }
}
Output
Caught: / by zero
Finally always runs!
Null or array error: java.lang.NullPointerException
💡 finally block
The finally block always executes — whether or not an exception occurs. It's used to release resources like closing files or DB connections. The only case it doesn't run: if System.exit() is called.

2.3 Multithreading

A thread is the smallest unit of execution. Java supports running multiple threads simultaneously (multithreading), allowing parallel tasks.

Thread Life Cycle [PYQ 2023-24]

Creating Threads – Two Ways

JAVA – Method 1: Extending Thread class
class MyThread extends Thread {
    @Override
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(Thread.currentThread().getName() + ": " + i);
        }
    }
}

public class ThreadDemo {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        t1.setName("Thread-A");
        t1.start(); // calls run() internally
    }
}
JAVA – Method 2: Implementing Runnable (Preferred!) [PYQ 2023-24]
class PrintNumbers implements Runnable {
    private String name;
    PrintNumbers(String name) { this.name = name; }

    @Override
    public void run() {
        for (int i = 1; i <= 5; i++) {
            System.out.println(name + ": " + i);
            try { Thread.sleep(100); } catch (InterruptedException e) {}
        }
    }
}

public class ThreadDemo2 {
    public static void main(String[] args) {
        Thread t1 = new Thread(new PrintNumbers("Thread-1"));
        Thread t2 = new Thread(new PrintNumbers("Thread-2"));
        t1.start();
        t2.start();
    }
}
💡 Why Runnable is Preferred
Since Java does not allow multiple inheritance, extending Thread prevents your class from extending any other class. Using Runnable is preferred because the class is free to extend another class.

Synchronization & Inter-thread Communication

JAVA – Even & Odd threads [PYQ 2024-25]
class Printer {
    private boolean printEven = false;

    synchronized void printOdd(int n) throws InterruptedException {
        while (printEven) wait();
        System.out.print(n + " ");
        printEven = true;
        notifyAll();
    }

    synchronized void printEven(int n) throws InterruptedException {
        while (!printEven) wait();
        System.out.print(n + " ");
        printEven = false;
        notifyAll();
    }
}

// Thread 1 prints odd: 1, Thread 2 prints even: 2, etc.
MethodPurpose
wait()Releases lock, thread enters WAITING state
notify()Wakes up one waiting thread
notifyAll()Wakes up all waiting threads
sleep(ms)Pauses thread for ms milliseconds (doesn't release lock)
join()Waits for another thread to complete

3.1 Functional Interfaces & Lambda Expressions [PYQ Both Years!]

A Functional Interface is an interface with exactly one abstract method. It can have multiple default or static methods. The @FunctionalInterface annotation enforces this.

JAVA – Functional Interface & Lambda
@FunctionalInterface
interface Greet {
    void sayHello(String name); // one abstract method
}

public class LambdaDemo {
    public static void main(String[] args) {

        // Before Java 8 – Anonymous class
        Greet g1 = new Greet() {
            public void sayHello(String name) {
                System.out.println("Hello, " + name);
            }
        };

        // Java 8+ – Lambda Expression (much cleaner!)
        Greet g2 = name -> System.out.println("Hello, " + name);

        g2.sayHello("Rahul");  // Hello, Rahul

        // Built-in Functional Interfaces
        java.util.function.Predicate<Integer> isEven = n -> n % 2 == 0;
        System.out.println(isEven.test(4));  // true

        java.util.function.Function<String, Integer> len = s -> s.length();
        System.out.println(len.apply("Java"));  // 4

        java.util.function.Consumer<String> print = s -> System.out.println(s);
        print.accept("Lambda is awesome!");
    }
}

3.2 Stream API [PYQ 2023-24]

Stream API (Java 8+) enables functional-style operations on collections — filtering, mapping, reducing — in a clean, readable way. Streams don't store data; they process it.

TypeOperationsReturns
Intermediatefilter(), map(), sorted(), distinct(), limit(), skip()Another Stream (lazy)
Terminalcollect(), forEach(), count(), sum(), reduce(), findFirst()Result / void
JAVA – Stream API Demo [PYQ: sum of even numbers 1-10]
import java.util.*;
import java.util.stream.*;

public class StreamDemo {
    public static void main(String[] args) {
        List<Integer> nums = new ArrayList<>();
        for (int i=1; i<=10; i++) nums.add(i);

        // Sum of even numbers from 1 to 10 (PYQ!)
        int sum = nums.stream()
                      .filter(n -> n % 2 == 0)   // intermediate: keep evens
                      .mapToInt(Integer::intValue) // intermediate: convert
                      .sum();                        // terminal: sum
        System.out.println("Sum of evens: " + sum);   // 30

        // More operations
        nums.stream()
            .filter(n -> n > 5)
            .map(n -> n * n)
            .sorted()
            .forEach(System.out::println); // 36, 49, 64, 81, 100

        // Collect to list
        List<String> names = Arrays.asList("anna", "bob", "charlie");
        List<String> upper = names.stream()
                                    .map(String::toUpperCase)
                                    .collect(Collectors.toList());
    }
}
Output
Sum of evens: 30

3.3 Modern Java Features

Switch Expression (Java 14+) [PYQ 2023-24]

JAVA
int day = 3;

// Old switch-case statement
switch (day) {
    case 1: System.out.println("Mon"); break;
    case 2: System.out.println("Tue"); break;
    default: System.out.println("Other");
}

// New switch expression (no break needed, returns value)
String dayName = switch (day) {
    case 1 -> "Monday";
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Other";
};
System.out.println(dayName); // Wednesday

// yield keyword (for multiline cases)
int score = switch (day) {
    case 1, 2 -> 10;
    case 3 -> {
        System.out.println("Midweek");
        yield 20;   // yield returns value from block
    }
    default -> 0;
};

5.1 Spring Framework Core [PYQ Both Years!]

What is Spring?

Spring is a comprehensive Java framework that simplifies enterprise application development. Its core features are Inversion of Control (IoC) and Dependency Injection (DI).

IoC vs DI [PYQ 2023-24 & 2024-25!]

ConceptInversion of Control (IoC)Dependency Injection (DI)
DefinitionDesign principle — control of object creation is given to the framework, not the programmerImplementation technique for IoC — framework injects required objects (dependencies)
Who creates objects?Spring Container (IoC container)Spring injects them automatically
RelationshipBroad conceptHow IoC is implemented
JAVA – Dependency Injection with Annotations
import org.springframework.stereotype.*;
import org.springframework.beans.factory.annotation.*;

@Service               // marks as a Spring-managed service bean
public class EmailService {
    public void sendEmail(String msg) {
        System.out.println("Email sent: " + msg);
    }
}

@Component             // marks as Spring bean (auto-detected)
public class NotificationService {

    @Autowired          // Spring automatically injects EmailService!
    private EmailService emailService;

    public void notify(String message) {
        emailService.sendEmail(message);
    }
}
// Without Spring, you'd write: emailService = new EmailService();
// With Spring, the framework handles object creation and injection!

Spring Boot is an opinionated extension of Spring that eliminates boilerplate configuration. It provides embedded servers, auto-configuration, and starter dependencies.

JAVA – REST Controller with CRUD [PYQ 2024-25]
import org.springframework.web.bind.annotation.*;
import java.util.*;

@RestController
@RequestMapping("/api/students")
public class StudentController {

    private List<String> students = new ArrayList<>(
        Arrays.asList("Rahul", "Priya", "Amit")
    );

    // GET all students
    @GetMapping
    public List<String> getAll() {
        return students;
    }

    // GET by index
    @GetMapping("/{id}")
    public String getById(@PathVariable int id) {
        return students.get(id);
    }

    // POST – add student
    @PostMapping
    public String add(@RequestBody String name) {
        students.add(name);
        return "Added: " + name;
    }

    // PUT – update student
    @PutMapping("/{id}")
    public String update(@PathVariable int id, @RequestBody String name) {
        students.set(id, name);
        return "Updated index " + id + " to " + name;
    }

    // DELETE
    @DeleteMapping("/{id}")
    public String delete(@PathVariable int id) {
        String removed = students.remove(id);
        return "Deleted: " + removed;
    }
}
