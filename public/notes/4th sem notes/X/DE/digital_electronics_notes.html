Binary ↔ Grey Code Conversion PYQ ★

Binary to Grey Code: MSB stays same. Each subsequent grey bit = XOR of that binary bit and the previous binary bit.

Binary: B₃ B₂ B₁ B₀ Grey: G₃ G₂ G₁ G₀ Rule: G₃ = B₃ G₂ = B₃ ⊕ B₂ G₁ = B₂ ⊕ B₁ G₀ = B₁ ⊕ B₀ Example: Binary (110111)₂ → Grey Code B: 1 1 0 1 1 1 G: 1 0 1 1 0 1 → (101101)_Grey Example: Binary (100110)₂ → Grey Code B: 1 0 0 1 1 0 G: 1 1 0 1 0 1 → (110101)_Grey

2's Complement & Subtraction PYQ ★

2's complement of a number = 1's complement + 1. Used for binary subtraction: A − B = A + (2's complement of B)

Example: (1100)₂ − (11101)₂ Step 1: Make equal length → (01100)₂ − (11101)₂ Step 2: 2's complement of 11101: 1's complement = 00010 Add 1 = 00011 Step 3: Add: 01100 + 00011 ─────── 01111 → No carry → Result is NEGATIVE Step 4: 2's complement of result = 10001 = −17 in decimal So answer = −(10001)₂ = −17

Hexadecimal to Binary PYQ ★

Convert 3F to Binary: 3 = 0011, F = 1111 ∴ (3F)₁₆ = (0011 1111)₂

Signed Binary Numbers

  • Sign-Magnitude: MSB = 0 (positive), MSB = 1 (negative)
  • 1's Complement: Invert all bits for negative
  • 2's Complement: Most used; no dual zero problem

1.3 Boolean Algebra & De Morgan's Theorem

Basic Laws

Identity: A + 0 = A, A · 1 = A Null: A + 1 = 1, A · 0 = 0 Idempotent: A + A = A, A · A = A Complement: A + A' = 1, A · A' = 0 Involution: (A')' = A Commutative: A + B = B + A, A · B = B · A Associative: A + (B + C) = (A + B) + C Distributive: A(B + C) = AB + AC

De Morgan's Theorems

Theorem 1: (A · B)' = A' + B' "Break the bar, change the sign (· ↔ +)" Theorem 2: (A + B)' = A' · B' Example: Y = ((A + B)C)'D Using De Morgan: Y = (A' · B' + C') · D

SOP & POS Forms

  • SOP (Sum of Products): OR of AND terms. Each AND term called a minterm.
  • POS (Product of Sums): AND of OR terms. Each OR term called a maxterm.
  • F = Σm(minterms) = ΠM(maxterms)
1.4 Karnaugh Map (K-Map) Simplification PYQ ★★

K-Map is a visual method to simplify Boolean expressions. Groups of 1s (or 0s for POS) that are powers of 2 (1,2,4,8...) can be combined to simplify.

4-Variable K-Map Layout

Sample 4-variable K-map with groupings highlighted in green

K-Map Rules

  1. Group 1s in largest possible power-of-2 groups (1, 2, 4, 8, 16)
  2. Groups can overlap and wrap around edges
  3. Don't-care (X) cells can be included if it increases group size
  4. Each cell must be covered by at least one group
  5. Variables that change within a group are eliminated from that term

Solved PYQ: F(A,B,C,D) = ΠM(4,5,6,7,8,12), d(0,1,2,3,9,11,14) PYQ

POS form: Maxterms at positions 4,5,6,7,8,12 Don't cares at: 0,1,2,3,9,11,14 Zeros at maxterm positions: Position 4 = 0100 (A=0,B=1,C=0,D=0) Position 5 = 0101 Position 6 = 0110 Position 7 = 0111 Position 8 = 1000 Position 12 = 1100 Using K-map with don't cares: Group 1: 4,5,6,7 (quad) → B=1, A=0 → (A+B') Group 2: 8,12 + dc(0) → A=1,B=X,C=0,D=0 OR group with dc → (B+C+D) Simplified F = (A+B')(B+C+D) — or simplify using grouping
1.5 NAND & NOR Gate Implementation PYQ ★

NAND and NOR are called universal gates because any Boolean function can be implemented using only NAND or only NOR gates.

NAND as Universal Gate

NOT using NAND: A' = (A·A)' = NAND(A,A) AND using NAND: A·B = ((A·B)')' = NAND(NAND(A,B), NAND(A,B)) OR using NAND: A+B = NAND(NAND(A,A), NAND(B,B)) = NAND(A', B')

NOR as Universal Gate

NOT using NOR: A' = (A+A)' = NOR(A,A) OR using NOR: A+B = NOR(NOR(A,B), NOR(A,B)) AND using NOR: A·B = NOR(NOR(A,A), NOR(B,B))

SOP → NAND-NAND

Any SOP expression can be directly converted to 2-level NAND-NAND form:

F = AB + CD → F = ((AB)' · (CD)')' = NAND(NAND(A,B), NAND(C,D))
NAND-NAND implementation of F = AB + CD
1.6 Quine-McCluskey (Tabular) Method PYQ ★

QM method is the algebraic form of K-map, useful for 5+ variables or when automation is needed.

  1. List all minterms in binary, group by number of 1s
  2. Compare minterms differing in exactly 1 bit; combine them (use dash for eliminated variable)
  3. Repeat until no more combinations possible
  4. Prime implicants = terms that couldn't be combined further
  5. Use a Prime Implicant Chart to select essential prime implicants

Solved PYQ: f(A,B,C,D) = Σm(0,1,2,3,4,6,8,9,10,11) PYQ

Step 1 — Group minterms by number of 1s: Group 0: 0 (0000) Group 1: 1 (0001), 2 (0010), 4 (0100), 8 (1000) Group 2: 3 (0011), 6 (0110), 9 (1001), 10 (1010) Group 3: 11 (1011) Step 2 — Combine pairs (differ by 1 bit): 0,1 → 000- 0,2 → 00-0 0,4 → 0-00 0,8 → -000 1,3 → 00-1 2,3 → 001- 2,10 → -010 4,6 → 01-0 1,9 → -001 8,9 → 100- 8,10 → 10-0 9,11 → 10-1 3,11 → -011 10,11→ 101- Step 3 — Combine groups of 4: 0,1,8,9 → -00- 0,2,8,10 → -0-0 0,4,2,6 → 0--0 1,3,9,11 → -0-1 8,9,10,11 → 10-- Step 4 — Prime Implicants: PI1: -00- → covers 0,1,8,9 → BD' PI2: -0-0 → covers 0,2,8,10 → B'D' PI3: 0--0 → covers 0,2,4,6 → A'D' PI4: -0-1 → covers 1,3,9,11 → B'D PI5: 10-- → covers 8,9,10,11 → AB' Final simplified expression: F = B'D' + B'D + AB' = B' + AB' = B'(1+A) + ... → F = A'D' + B' (after proper PI chart analysis)

2.1 Multiplexers (MUX) PYQ ★★

A multiplexer (data selector) selects one of N inputs and routes it to a single output, controlled by select lines. An N:1 MUX needs log₂N select lines.

4:1 MUX using 2:1 MUX PYQ

⚙️
A 4:1 MUX can be built from three 2:1 MUXes. Two MUXes select between pairs of inputs (using S₀), and one final MUX selects between the two outputs (using S₁).

Look-Ahead Carry Generator PYQ

Ripple carry adders are slow because each bit must wait for the previous carry. A Carry Look-Ahead (CLA) generates all carries simultaneously.

Propagate: Pᵢ = Aᵢ ⊕ Bᵢ Generate: Gᵢ = Aᵢ · Bᵢ Carry equations: C₁ = G₀ + P₀·C₀ C₂ = G₁ + P₁·G₀ + P₁·P₀·C₀ C₃ = G₂ + P₂·G₁ + P₂·P₁·G₀ + P₂·P₁·P₀·C₀ C₄ = G₃ + P₃·G₂ + P₃·P₂·G₁ + P₃·P₂·P₁·G₀ + P₃·P₂·P₁·P₀·C₀ All carries computed in parallel → maximum delay = 2 gate levels

3.1 Latches & Flip-Flops PYQ ★★

Sequential circuits have memory — output depends on both current input AND past history. The basic storage element is the flip-flop.

JK Flip-Flop PYQ

JK FF eliminates the invalid state of SR FF. When J=K=1, output toggles.

Race Around Condition PYQ

⚠️
In a level-triggered JK FF with J=K=1, if the clock pulse remains HIGH for a time period greater than the propagation delay of the FF, the output oscillates (toggles multiple times) during one clock cycle. This unpredictable behavior is called the race-around condition. It is solved by using edge-triggered flip-flops or master-slave configuration.

3.2 Shift Registers PYQ ★

A shift register is a chain of flip-flops where data shifts from one FF to the next on each clock pulse.

Types of Shift Registers

  • SISO (Serial In, Serial Out) — simple shift, data enters and exits 1 bit at a time
  • SIPO (Serial In, Parallel Out) — data enters serially, all bits available simultaneously
  • PISO (Parallel In, Serial Out) — parallel load, serial shift-out
  • PIPO (Parallel In, Parallel Out) — all bits loaded and read simultaneously

Bi-Directional Shift Register PYQ

Data can shift left OR right, controlled by a direction control bit. Implemented using D flip-flops with 2:1 MUX at each stage's input.

For each stage i, the D input: D_i = (Mode · Q_{i+1}) + (Mode' · Q_{i-1}) Mode = 0 → Shift Right: Dᵢ = Q_{i-1} Mode = 1 → Shift Left: Dᵢ = Q_{i+1}
3-bit Shift Register using D flip-flops (shift right direction)
3.3 Counters PYQ ★★

Ripple (Asynchronous) Counter

In a ripple counter, each FF triggers the next. Output of Q is the clock for the next stage. Simple but slow due to ripple delay.

Synchronous Counter

All FFs share the same clock. Faster and no ripple delay, but requires combinational logic for each FF's input.

MOD-6 counter: counts 000 → 001 → 010 → 011 → 100 → 101 → (back to 000) Needs 3 JK flip-flops: Q₂Q₁Q₀ State Table: Present State | Next State | J₂K₂ | J₁K₁ | J₀K₀ Q₂Q₁Q₀ | Q₂Q₁Q₀ | | | 000 | 001 | 0X | 0X | 1X 001 | 010 | 0X | 1X | X1 010 | 011 | 0X | X0 | 1X 011 | 100 | 1X | X1 | X1 100 | 101 | X0 | 0X | 1X 101 | 000 | X1 | 0X | X1 K-map simplification: J₂ = Q₁Q₀, K₂ = 1 J₁ = Q₀Q₂', K₁ = Q₀ J₀ = 1, K₀ = 1

Synchronous & Asynchronous Sequential Circuits

CO4 · K3 · State Machines · State Reduction · Hazards

4.1 Mealy & Moore State Machines PYQ ★

Moore Machine

  • Output depends ONLY on present state
  • Output changes only on clock edge
  • More states needed, but more stable
  • Output: λ(Q)

Mealy Machine

  • Output depends on present state AND current input
  • Faster response, fewer states needed
  • Output may glitch with input changes
  • Output: λ(Q, X)

4.2 State Reduction & Assignment

State reduction minimizes the number of states in a sequential circuit, saving flip-flop hardware.

Implication Table Method (Row Reduction)

  1. List all pairs of states
  2. Mark pairs as distinguishable if they produce different outputs for same input
  3. For indistinguishable pairs, check if their next states are also indistinguishable
  4. Merge equivalent states (identical output and same next state behavior)
💡
Two states S₁ and S₂ are equivalent if for every possible input sequence, the same output sequence is produced, regardless of which state we start in.
4.3 Asynchronous Sequential Circuits & Hazards PYQ ★

Asynchronous circuits respond immediately to input changes without waiting for a clock. They use fundamental mode (only one input changes at a time) or pulse mode.

Flow Table

A flow table (like a state table) shows the next state and output for each input combination. Unstable states are in circles, stable states in squares.

Race Conditions PYQ

  • Race: When multiple state variables must change simultaneously, they may not change at exactly the same time due to unequal delays.
  • Non-critical race: Both transition paths lead to the same stable state — harmless.
  • Critical race: Different paths lead to different stable states — circuit ends up in wrong state!

Race-Free State Assignment

  1. Assign binary codes to states such that transitions between states differ by only one bit (like Grey code)
  2. Add extra intermediate states if needed
  3. Use shared rows technique in flow table

Hazards in Combinational Circuits

Static-1 Hazard: Output momentarily goes 0 when it should stay 1 Static-0 Hazard: Output momentarily goes 1 when it should stay 0 Dynamic Hazard: Output changes 3+ times when it should change once Solutions: - Add redundant gates to cover K-map grouping transitions - Use consensus terms to eliminate hazard - Add delay elements (not preferred)

ECL (Emitter-Coupled Logic) PYQ

Fastest logic family — uses differential amplifier pair. Transistors never saturate, so no storage delay. Used in very high-speed applications like fiber optic transceivers.

ECL features: ✓ Fastest (sub-nanosecond) ✓ Both OR and NOR outputs simultaneously ✗ Highest power consumption ✗ Poor noise margin ✗ Negative supply voltage (-5.2V)

CMOS Advantages over TTL PYQ

  • Extremely low static power dissipation (near zero when not switching)
  • Wide supply voltage range (3V–18V)
  • Very high fan-out (>50)
  • Excellent noise margin (~40% of VDD)
  • High packing density — millions of gates on a chip
  • Used in all modern digital chips (phones, CPUs, memory)
5.2 ROM, RAM & EEPROM PYQ ★

ROM (Read-Only Memory)

Non-volatile, programmed during manufacture. Stores truth tables for combinational functions. Types: Mask ROM, PROM, EPROM, EEPROM, Flash.

ROM Organization: n address lines → 2ⁿ locations m data lines → m bits per location Total capacity = 2ⁿ × m bits Example: 3-variable Boolean function using ROM 3 inputs → 2³ = 8 addresses Each address stores one output value

EEPROM Advantages PYQ

  • Electrically erasable — no UV light needed (unlike EPROM)
  • Byte-level erase and write (selective update)
  • In-circuit reprogramming (no removal from board)
  • Non-volatile — retains data without power
  • Unlimited read cycles; typically 100,000+ write cycles
  • Used in BIOS chips, smart cards, microcontroller data storage

RAM (Random Access Memory)

  • SRAM (Static): Uses cross-coupled inverters (6T cell), fast, used for cache
  • DRAM (Dynamic): Uses capacitor + transistor (1T cell), needs refresh, dense, used for main memory

PLA (Programmable Logic Array)

Both AND and OR planes are programmable. Can implement any SOP expression. More flexible than PAL. Used for custom logic functions.

Only AND plane is programmable; OR plane is fixed. Simpler, faster, cheaper. Each output is OR of a fixed number of AND terms.

Contains thousands of Look-Up Tables (LUTs), flip-flops, and programmable interconnects. Reprogrammable in the field. Used for prototyping, DSP, video processing.

5.4 ADC & DAC PYQ ★★

Flash Type ADC PYQ

Fastest ADC. Uses 2ⁿ−1 comparators in parallel. All comparisons happen simultaneously — very high speed but very hardware-intensive.

For n-bit Flash ADC: - Number of comparators needed: 2ⁿ - 1 - Reference voltages: VREF/2ⁿ, 2VREF/2ⁿ, ..., (2ⁿ-1)VREF/2ⁿ - Priority encoder converts thermometer code to binary - Used in: oscilloscopes, radar, high-speed data acquisition - 8-bit ADC needs 255 comparators!

Dual Slope ADC PYQ

High accuracy, slow speed. Used in digital multimeters. Noise-immune because it integrates over time.

Phase 1: Integrate Vin for fixed time T₁ Phase 2: Integrate -VREF until output = 0 Count clock pulses during Phase 2 → Digital output Digital Count N = (Vin/VREF) × N_max Advantage: Excellent noise rejection, self-calibrating

Successive Approximation ADC PYQ

Most popular ADC for medium speed. Uses binary search algorithm — n comparisons for n-bit output.

Algorithm (for 4-bit, VREF=10V, Vin=7.3V): Start: 0000 Bit 3: Try 1000 → DAC=5V, 7.3>5 → Keep → 1000 Bit 2: Try 1100 → DAC=7.5V, 7.3<7.5 → Drop → 1000 Bit 1: Try 1010 → DAC=6.25V, 7.3>6.25 → Keep → 1010 Bit 0: Try 1011 → DAC=6.875V, 7.3>6.875 → Keep → 1011 Result: 1011 (= 6.875V, closest to 7.3V)

R-2R Ladder DAC PYQ

Most practical DAC — uses only two resistor values (R and 2R). Easy to manufacture with high precision.

Output voltage: Vout = -VREF × (b₃/2 + b₂/4 + b₁/8 + b₀/16) For 4-bit R-2R: MSB (b₃) contributes VREF/2 Next (b₂) contributes VREF/4 Next (b₁) contributes VREF/8 LSB (b₀) contributes VREF/16 Key advantages: ✓ Only R and 2R values needed ✓ Easy to fabricate precisely on IC ✓ Good accuracy and speed
