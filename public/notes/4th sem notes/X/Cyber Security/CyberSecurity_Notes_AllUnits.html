1.1 What is Cybercrime?

Cybercrime is any illegal activity carried out using a computer, network, internet, or digital device. It can target the computer itself, use a computer as a tool, or both.

Origin of the Word "Cyber"

The word cyber comes from cybernetics — the science of communication and control in machines. After the rapid growth of the internet in the 1990s, digital crimes became common, and the term "cybercrime" was widely adopted.

Characteristics of Cybercrime
🌐
Borderless
No geographical limits — attacker can be in any country.
🕵️
Anonymous
Criminals hide behind VPNs, proxies, fake IDs.
⚡
Fast Execution
Attacks can happen in milliseconds.
🔍
Hard to Trace
Digital evidence easily erased or hidden.
💸
Low Cost, High Impact
Cheap tools cause billion-dollar damage.
Three Roles of a Computer in Cybercrime
🎯
Target
Computer is the victim. Example: Hacking a server to steal data.
🔧
Tool
Computer used to commit crime. Example: Sending phishing emails.
🔄
Both
A hacked machine is also used to attack others (botnet).
EXAMPLE

A hacker in another country attacks Indian bank servers remotely — computer is both tool and target.

Step 1: Reconnaissance — Information Gathering ▼

Attacker collects information about the target without touching the system. Sources: company websites, LinkedIn, Google, public records (OSINT).

EXAMPLE

Checking a company's employee list on LinkedIn to find email patterns.

Step 2: Scanning — Finding Vulnerabilities ▼

Attacker scans the target system for open ports, running services, and known vulnerabilities using tools like Nmap, Nessus.

EXAMPLE

Finding an open port 3306 (MySQL) on a server — potential SQL injection target.

Step 3: Gaining Access — Exploiting Weakness ▼

Attacker uses found vulnerabilities to enter the system. Methods: SQL injection, phishing, buffer overflow, password cracking.

Step 4: Maintaining Access — Persistence ▼

Attacker installs a backdoor or rootkit to maintain long-term access even if initial vulnerability is patched.

Step 5: Covering Tracks — Hiding Evidence ▼

Attacker deletes log files, uses proxy chains, and removes malware to avoid detection and investigation.

1.8 Cyber Stalking, Cybercafes & Botnets

2.1 Introduction to Mobile & Wireless Devices

Mobile devices are portable computing devices that can process, store, and transmit data wirelessly. They include smartphones, tablets, laptops, smartwatches, and IoT devices.

Wireless communication means transmitting data without physical cables, using radio waves via technologies like Wi-Fi (802.11), Bluetooth, NFC, and 3G/4G/5G.

Why Are Mobile Devices a Security Concern?

📌 Earlier, sensitive data sat in desktop computers at fixed locations. Now it's in our pockets — banking apps, office email, cloud storage, OTPs. If a phone is compromised, the attacker can access everything.

EXAMPLE

If attacker gains access to your mobile: Reads OTP → Accesses bank app → Resets passwords → Steals money. One device = full digital identity compromised.

2.2 Proliferation of Mobile Devices

Proliferation means rapid increase in number. India saw explosive growth due to cheap internet (Jio), affordable smartphones, Digital India movement, WFH culture, and online education.

⚠️

Engineering Concept — Attack Surface: More devices = More entry points. Earlier: 1 desktop = 1 attack surface. Now: Laptop + Mobile + Tablet + Smartwatch + Home router = 5+ attack surfaces. More devices → More vulnerabilities → More risk.

2.5 Security Challenges of Mobile Devices
📵 Physical Loss or Theft ▼

Mobile is portable and easily lost. Risk: Data exposure, banking app misuse. Solution: Device encryption, remote wipe capability, biometric lock.

🦠 Malware Infection ▼

APK files from unknown sources carry spyware, trojans, ransomware. Never install apps from untrusted sources.

🔑 Weak Authentication ▼

Using PIN 1234 or simple patterns is dangerous. Solution: Strong password + Biometric + Multi-Factor Authentication (MFA).

📶 Unsecured Wireless Communication ▼

Public WiFi is a major attack vector. Attacks: Packet sniffing (capturing data), Evil Twin attack (fake WiFi with same name). Always use VPN on public networks.

📤 Data Leakage via Apps ▼

Apps that request unnecessary permissions (contacts, camera, microphone, location, storage) can leak sensitive data if compromised. Review app permissions regularly.

3.3 Password Cracking

Password cracking is an attempt to recover or guess passwords by various techniques.

💪 Brute Force Attack ▼

Tries every possible combination systematically (aaa, aab, aac... zzz). Guaranteed to succeed eventually but very slow for complex passwords.

EXAMPLE

Tool tries: 000000, 000001, 000002 … 999999 until password found.

📖 Dictionary Attack ▼

Tries common passwords and words from a dictionary file. Faster than brute force but not guaranteed.

EXAMPLE

Tries: password, 123456, qwerty, admin, welcome123...

🌈 Rainbow Table Attack ▼

Uses precomputed hash values for fast lookup. If system stores passwords as hashes without salt, attacker can match instantly. Prevention: Add salt (random data) before hashing.

🔄 Credential Stuffing ▼

Uses leaked username-password pairs from one breach on other websites. Works because users reuse passwords. Prevention: Unique password for every site.

3.7 DoS & DDoS Attacks

DoS (Denial of Service) — A single attacker floods a server with requests, consuming all resources, causing it to crash and become unavailable to legitimate users.

DDoS (Distributed Denial of Service) — Thousands of infected systems (botnet) simultaneously flood a target. Extremely powerful and hard to stop.

EXAMPLE

10,000 bots each sending 1000 requests/second to one website = 10 million requests/second → server crashes → real users cannot access site.

3.8 SQL Injection

SQL Injection is an attack on a database via web application input fields. Attacker inserts malicious SQL code to manipulate database queries.

If a developer writes vulnerable code:

SELECT * FROM users WHERE username = '"+ input +"'

If attacker types: ' OR '1'='1

Query becomes:

SELECT * FROM users WHERE username = '' OR '1'='1' -- This is ALWAYS TRUE → bypasses login!
🛡

Prevention: Use Prepared Statements and Parameterized Queries. Never concatenate user input directly into SQL strings. Validate and sanitize all inputs.

3.9 Buffer Overflow

Buffer Overflow occurs when a program writes more data into a memory buffer than it was allocated, overwriting adjacent memory — potentially causing crash or execution of malicious code.

// Vulnerable C code char buffer[10]; // Allocated 10 bytes gets(buffer); // User inputs 20 chars → OVERFLOW! // Overwrites adjacent memory → attacker injects shellcode
🛡

Prevention: Always check bounds before writing to buffers. Use safe languages (Java, Python). Enable Stack Protection (ASLR, Stack Canaries).

4.1 Introduction to Computer Forensics

Computer Forensics is the process of identifying, collecting, preserving, analyzing, and presenting digital evidence in a legally admissible manner to investigate cybercrimes.

Digital Evidence is any information stored or transmitted in digital form that can be used in a court of law. Examples: Emails, chat messages, browser history, server logs, CCTV recordings, hard disk data.

📌 Engineering Analogy: Digital forensics is like debugging a crashed program — you reverse-engineer the crime by analyzing logs, files, and digital traces to understand what happened, when, and who did it.

4.2 Digital Forensics Science & Branches
💻
Computer Forensics
Analyze PCs, laptops, hard disks. Used in desktop cybercrime cases.
🌐
Network Forensics
Analyze network traffic logs, packet captures. Trace attack path.
📱
Mobile Forensics
Analyze smartphones, tablets — call logs, messages, apps.
☁️
Cloud Forensics
Investigate crimes involving cloud storage. Jurisdiction challenges.
🗄
Database Forensics
Analyze database access logs, detect unauthorized modifications.
EXAMPLE

Ransomware attack investigation: Computer forensics (infected system) + Network forensics (traffic logs) + Mobile forensics (attacker communication) + Cloud forensics (cloud backup).

4.3 Types of Digital Evidence
⚡
Volatile Data
Temporary. Disappears when power is OFF. Examples: RAM data, running processes, network connections, logged-in users. Must be collected FIRST!
💾
Non-Volatile Data
Permanent. Remains after shutdown. Examples: Hard disk files, SSD data, USB drives, email archives. Can be collected later.
⚠️

Critical Rule: Always collect volatile data FIRST before shutting down the machine. Once power is off, RAM data (open files, passwords, running processes) is permanently lost.

Properties of good digital evidence: It must maintain integrity (unchanged), be legally admissible, be properly documented, and be authentic.

Integrity maintained using: Hash functions (SHA-256), Write blockers, Disk imaging.

4.4 Digital Forensics Lifecycle

The forensic lifecycle is a systematic process to investigate cybercrime. Every step must be documented.

Digital Forensics Lifecycle — 6 Steps
1
Identification
Recognize that a crime has occurred. Identify devices and systems involved.
2
Preservation
Secure evidence. Do NOT modify original system. Use write blockers & disk imaging.
3
Collection
Copy data safely using forensic imaging tools. Work on copy, not original.
4
Examination
Extract relevant data. Recover deleted files. Filter useful information.
5
Analysis
Interpret extracted evidence. Build timeline. Identify suspect behavior.
6
Presentation
Submit formal report to court. Expert witness testimony if needed.
⭐

Golden Rule of Forensics: NEVER work on original evidence. Always create a forensic image (bit-by-bit copy) and work on that copy.

4.5 Chain of Custody

Chain of Custody is a documented record that shows who collected the evidence, when, where, and every person who handled it thereafter. It ensures evidence authenticity and admissibility in court.

Why important? If evidence is tampered or chain is broken → case can be dismissed. Every evidence transfer must be documented with date, time, and signatures.

EXAMPLE

Police seize a laptop: Date/time recorded → Officer's name recorded → Sealed with evidence bag → Storage location logged → Each transfer signed. This chain ensures the laptop presented in court is the same one seized from the crime scene.

If phishing email received, forensics examines header to find: Was the "From" address spoofed? What is the real server IP? Which country did it originate from?

Network Forensics investigates network traffic and logs to detect intrusions, trace attacker IP addresses, and analyze attack patterns.

What is analyzed: Packet captures (PCAP files), Firewall logs, Server access logs, IDS/IPS alerts, DNS query logs.

5.1 Information Security Policy

Information Security Policy (ISP) is a formal written document that defines what information needs protection, who is responsible, how protection should be implemented, and consequences of policy violations. It is the security rulebook of an organization.

Why Is It Needed?

Modern organizations store customer data, financial records, business secrets, and employee data. Without a policy:

  • Employees may share passwords or write them on sticky notes
  • Data may be copied to personal devices without authorization
  • No standard security procedures lead to inconsistent protection
  • Data breaches cause legal penalties under DPDP Act 2023
EXAMPLE

No password policy → Employee uses "company123" → Easy to crack → Data breach → Heavy fine under DPDP Act 2023.

Types of Security Policies
🏢
Organizational Policy
High-level rules for the entire organization. Broad security framework.
📋
Issue-Specific Policy
Focused on one specific issue. Examples: Email policy, Social media policy, BYOD policy.
⚙️
System-Specific Policy
Technical configuration rules. Examples: Firewall rules, server configuration, patch management.
Key Policy Components
  • Password Policy — Complexity requirements, rotation schedule
  • Data Classification Policy — Public / Internal / Confidential / Restricted
  • Access Control Policy — Role-based access, least privilege principle
  • Backup and Recovery Policy — Frequency, storage location, testing
  • Incident Response Policy — Steps when breach occurs
  • Remote Work Policy — VPN requirements, allowed devices
5.2 Indian Cyber Law — IT Act 2000

Information Technology Act 2000 is India's primary law governing cybercrime and electronic commerce. It provides legal recognition to electronic records and digital signatures, and defines punishments for cyber offenses.

Why IT Act Was Needed
  • Before 2000, no law covered online crimes in India
  • No legal status for digital signatures or e-contracts
  • Rapid growth of internet commerce needed legal framework

5.3 Digital Personal Data Protection Act 2023 (DPDP Act)

DPDP Act 2023 is India's comprehensive personal data protection law. It protects digital personal data, regulates how companies process data, gives rights to individuals, and imposes heavy penalties for data misuse.

Why Was This Act Needed?
  • Massive data collection by social media, apps, fintech companies
  • Frequent large-scale data leaks in India
  • No dedicated personal data protection law existed before
  • India's Supreme Court declared privacy a fundamental right (2017)
Key Definitions
👤
Data Principal
The person whose data is being collected and processed. Example: You, the Instagram user.
🏢
Data Fiduciary
The organization that collects and processes data. Example: Instagram/Meta company.
Rights of Data Principal (Individual)
  • Right to know — How their data is used and for what purpose
  • Right to correction — Correct inaccurate personal data
  • Right to erasure — Delete personal data (Right to be forgotten)
  • Right to grievance redressal — Complain about data misuse
  • Right to nominate — Nominate someone to exercise rights after death
Obligations of Data Fiduciary (Company)
  • Obtain free and informed consent before collecting data
  • Use data only for specified purpose
  • Protect data with appropriate security measures
  • Notify individuals and government if data breach occurs
  • Appoint Data Protection Officer (DPO) if required
  • Delete data when no longer needed (data minimization)
EXAMPLE

Fintech company leaks Aadhaar numbers + bank account details of 1 crore customers → DPDP Act 2023 → Heavy penalty potentially in crores of rupees.

5.4 Intellectual Property (IP) Issues

Intellectual Property (IP) refers to legal protection for creations of the human mind — inventions, artistic works, designs, and symbols. In the cyber world, IP theft is very common due to ease of digital copying.

IP Issues in Cybercrime
  • Software piracy — using software without proper license
  • Torrent downloads — illegal distribution of movies, music, books
  • Logo misuse — creating fake websites with similar logos
  • Domain name spoofing — registering confusingly similar domain names
  • Code plagiarism — copying open-source code without attribution
5.5 Patent, Copyright & Trademark
🔬

Protects inventions & new technology. Duration: 20 years. Governed by: Patents Act 1970. Registration: Mandatory. Example: New cybersecurity hardware chip.

Protects creative works. Duration: Life + 60 years. Governed by: Copyright Act 1957. Registration: Automatic. Example: Software source code, app, website content.
